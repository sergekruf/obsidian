## Когда нужно

При настройке Claude Code с нуля или когда хочешь сделать работу быстрее и умнее.

## Как установить

```bash
# Официальный маркетплейс уже подключён по умолчанию
/plugin install <имя>@claude-plugins-official

# Демо-маркетплейс от Anthropic (добавить вручную)
/plugin marketplace add anthropics/claude-code
/plugin install <имя>@anthropics-claude-code

# После установки — перезагрузить без рестарта
/reload-plugins
```

## 🔥 Git и код — первым делом

### commit-commands

```
/plugin install commit-commands@anthropics-claude-code
```

Добавляет `/commit-commands:commit` — Claude сам стейджит файлы, пишет сообщение коммита и делает коммит. Экономит кучу времени.

### pr-review-toolkit

```
/plugin install pr-review-toolkit@claude-plugins-official
```

Агент для code review PR. Анализирует изменения, находит баги и проблемы.

## 🧠 Code Intelligence — умная навигация по коду

Claude начинает видеть ошибки типов и импортов сразу после редактирования файла — без запуска компилятора.

### Python

```
/plugin install pyright-lsp@claude-plugins-official
# Требует: pip install pyright
```

### TypeScript / JavaScript

```
/plugin install typescript-lsp@claude-plugins-official
# Требует: npm install -g typescript-language-server typescript
```

### Go

```
/plugin install gopls-lsp@claude-plugins-official
# Требует: go install golang.org/x/tools/gopls@latest
```

### Rust

```
/plugin install rust-analyzer-lsp@claude-plugins-official
# Требует: rustup component add rust-analyzer
```

**Что даёт:** после каждого редактирования файла Claude автоматически видит ошибки и исправляет их в том же ходу. Навигация: перейти к определению, найти все использования, посмотреть типы.

## Нюансы

- Плагины исполняют код на твоей машине — устанавливай только из доверенных источников
- LSP плагины требуют установленного бинарника (проверь `/plugin` → вкладка Errors)
- `rust-analyzer` и `pyright` могут есть много памяти на больших проектах — отключай если тормозит
- Версия Claude Code должна быть 1.0.33+ для поддержки плагинов (`claude --version`)
