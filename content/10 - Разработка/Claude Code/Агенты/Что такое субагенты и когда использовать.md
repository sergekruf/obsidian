# Что такое субагенты и когда использовать

## Что это

Claude Code может запускать дочерние агенты для параллельного выполнения задач.
Каждый субагент — отдельный контекст и отдельный расход токенов.

## Когда использовать

- Задачи можно разбить на независимые части
- Нужно проверить один и тот же код разными подходами
- Большой проект: один агент пиш
  ет тесты, другой — документацию

## Как запустить

Просто описать в запросе:

```
"Запусти параллельно два агента:
- первый пусть напишет unit-тесты для auth модуля
- второй пусть напишет документацию к API"
```

## Нюансы

- Каждый субагент тратит отдельные токены — следи за /cost
- Контексты не общаются напрямую — только через файлы на диске
- Не используй для задач с общим изменяемым состоянием
